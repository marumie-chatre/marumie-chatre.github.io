## 4. 厳守ルール（破ったら不採用）

### 4-1. 事実・コンプラ
- 🚫 **偽口コミ禁止**（景表法ステマ規制）。口コミは `app/reviews.json` の**実投稿を引用**（改変なし／短縮は文末ごと）。架空の感想・☆・日時の捏造は厳禁。
- 🚫 **景表法NG**：「業界初/No.1/最大/最強」等の実証なし断定。競合の実名ネガティブ断定。**未確認数字**（例：ブライト「140店舗」「老舗20年」、アット「95店舗」、FT「98.4%」「身バレゼロ実績」、身バレ「0.1%」、面接「合格率95%」等）は**載せない**。
- ✅ 事実は検索/公式で確認し【調】＝出典明示（コモディティは主役にせず淡々と）。見解はみなみの一次判断【一】を重ねる。分からないものは「未確認」と正直に。

### 4-2. 安心ファースト（§MASTER H-3・最重要）
- ゴールは**不安を消して背中を押す**。正直さは“信頼を作る道具”で、暴露が目的ではない。同じ事実を**安心の根拠に変換**。
- 逮捕・流出・罰金などの強い喚起を、辞書/比較/選び方/属性記事で並べない（語りすぎない）。詳しい注意は身バレ/安全カテゴリへ内部リンクで送る。
- 読後感は**安心＞警戒**。希望と次の行動で締める。
- **各社の身バレ対策はランク付けしない**（§A-4）。見るのは「面接で具体的に説明できるか」。

### 4-3. 文体 C-2（AI感を消す）
- **断定・安心の保証はOK**（みなみの温かい語り・言い切りは強み）。やわらげすぎない（「〜と思います」連発は逆効果）。
- **同じ語尾の機械的反復をしない**（〜ね／〜なんです／〜ますよね の連発回避＝語尾に変化）。
- **本文に（）を多用しない**（補足は文に溶かす／「｜」「──」で）。`私（みなみ）`→`現役チャットレディ4年の私、みなみ`。
- **内部用語・略語を本文に出さない**：5軸→5つの基準／サムネ→サムネイル写真／プロフ→プロフィール／PT→ポイント。**本文・見出しに「FT」は使わない**（フェアリーテイルと書く）。「両対応/アダ/ノンアダ(略)」も使わない。

### 4-4. デザイン C-3（/profile体裁・page.tsx化時）
- 枠（TipBox/PointBox/WarningBox）はアイコン＋見出しを上の行・本文は左から。`<br />`詰めにせず **CleanList**（余白を詰めて整列）。
- 長い列挙・手順・つまずき等は**番号カード**（番号バッジ＝淡い面＋緑数字。塗りつぶし円は野暮）。例：barebure対策／kazoku行動の変化／jimusho-erabiつまずき5点／mensetsu流れ5ステップ。
- みなみ吹き出し（MinamiBubble）は淡い緑背景。情報の種類ごとに枠・余白を十分に。

### 4-5. お金・送客
- 報酬率は**在宅40%・通勤30%が業界標準**。高率（50〜60%・最大時給◯円）は魅力でなく**注意喚起**で。
- **通勤の報酬率は30%で一律**（新人/上位で変わらない）。「最大◯%・ランクで上がる」と**変動するのは主に在宅・海外サイト**を扱う事務所。率を高く見せ手数料で引く“盛る”事務所はまれにある→「率より手元に残る額・サポート」で見る。〔オーナー一次・2026-06-27〕
- 収入は誇張しない。**時給で見る**のが現実的（みなみ実感：1か月1,200〜2,500円→半年-1年2,000〜3,600円→1年〜4,000円〜・個人差・保証でない）。バーチャルは**最初は月3〜10万を目標**。月◯十万・月50-80万等の誇大はNG。
- **FT送客は構造で**（ランキング・関連・比較の納得）。本文直推し・btn連打はしない。FTの推し方は「**自分に合わせて提案してくれる安心**」（会話のヒント・髪型メイク・顔出しなしの稼ぎ方・暮らし/職種に合わせる）。「ノンアダルトだから流出しない」等の回りくどい理由は使わない。

### 4-6. 読者誘導・タイトル・画像（今セッションの確定事項）
- **「何社も回って比較」は誘導しない**（読者を競合に分散させない）。比較は**まるみえのランキング・口コミで完結→納得できる一社へ**着地。読者保護の「急かす店で即決しない」だけ残す。みなみの実体験（遠回り）は残しつつ「あなたは繰り返さなくていい」へ転換。〔オーナー方針・2026-06-27〕
- **「現役」だけにしない＝現役チャットレディと明示**（“何の現役か”が伝わるよう）。要所（メタ説明・各記事の冒頭初出・末尾の但し書き・カード・タイトル）で明示。本文2回目以降や見出しは「現役4年」のままでOK（くどさ回避＝B方針）。
- **タイトル規約**：ルートに `title:{template:"%s｜まるみえチャトレ"}` があり**全ページに自動でブランド名が付く**。各ページのメタ title に `【まるみえチャトレ】`/`｜まるみえチャトレ` を**手書きしない**（二重になる）。主KW・数字は前半13字以内。疑問形フックはOK（「怪しくない？」）／煽り語（詐欺・カラクリ）は避ける。**関連リンクの文言は各記事の実タイトルをそのまま使う**（アンカーテキストSEO）。
- **カバー画像運用**：同名で上書きすると画像最適化/CDN/ブラウザの**キャッシュに旧版が残る**。差し替え時は**新しいファイル名にリネーム**して全参照（記事カバー・articles.ts・QHubList・WorriesFooter）を張り替える。日本語の説明的ファイル名でOK（例 `家族、彼氏ばれ.jpg`）。L3カバーは素の`<img>`で高さ自動＝自然比率（歪まない）。
- **用語辞典(/yougo)は表に出さない**（ブログ記事から /yougo 本体へのリンクは置かない。`/yougo/houshu-60` は独立記事なのでリンクOK）。

### 6-3. ポーズ（記事内容に合わせてランダムに選ぶ・毎回同じにしない）
- 解決・前向き → 両手で**万歳**／グッドサイン（例：選び方）
- 正直・誠実に答える → 軽く**胸に手をあてる**／うなずく（例：怪しい？）
- 面接・これから → スマホを手に、少し緊張＋前向き（例：面接の流れ）
- 説明・教える → 軽く片手を上げて「お答えします」（例：身バレ疑問）
- 安心・寄り添い → やわらかい笑顔で頬に手（例：家族バレ）
→ 記事テーマに合うものを1つ選ぶ。

### 6-4. タイトル文字の割り当て
記事タイトルを4行に分解：**問い→主語→キーワード(大きく強調)→安心/解決の言葉**。
例「チャットレディは／家族や彼氏に／バレる？／よくある原因とバレない対策」。
